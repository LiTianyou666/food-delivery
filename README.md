\# Food Delivery Platform



This is a web-based food delivery application that connects customers, merchants, and administrators.



\## Architecture

\- \*\*Frontend\*\*: HTML, CSS, JavaScript

\- \*\*Backend\*\*: Node.js / Express

\- \*\*Database\*\*: PostgreSQL (or your stack)
